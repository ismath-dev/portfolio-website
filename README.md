# 🌐 Personal Portfolio Website

## 📖 About The Project
This is a responsive personal portfolio website developed using HTML5 and CSS3. The project was created to showcase my frontend development skills, personal projects, and learning journey in web development.

The website features a clean user interface, responsive layout, and structured sections including About, Skills, Projects, and Contact.

## 🚀 Features
- Responsive portfolio design
- Modern and clean user interface
- About Me section
- Skills showcase
- Projects section
- Contact information section
- Beginner-friendly frontend structure

## 🛠️ Built With
- HTML5
- CSS3
- Visual Studio Code
- GitHub

## 📂 Project Setup
To run this project locally:

1. Download or clone the repository
2. Open the project folder in Visual Studio Code
3. Open `index.html`
4. Run the project using Live Server
